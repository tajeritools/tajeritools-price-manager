# TajeriTools Price Manager

برنامهٔ فارسی برای مدیریت کاتالوگ‌ها و قیمت‌نامه‌های ابزار.

## قابلیت‌ها
- آپلود و حذف PDF، تصویر، Excel و CSV
- استخراج متن PDF و صفحات قابل جستجو
- جستجو با نام، کد مدل، برند یا بخشی از مشخصات
- نمایش تصویر/پیش‌نمایش صفحهٔ مرتبط و متن استخراج‌شده
- تعریف فرمول قیمت جدا برای هر برند
- اجرای گروهی فرمول روی محصولات استخراج‌شده
- بازبینی و ویرایش قیمت‌ها قبل از خروجی
- ساخت PDF فارسی مناسب ارسال در واتس‌اپ و روبیکا
- ذخیرهٔ اطلاعات در SQLite

## اجرای برنامه

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
# source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

سپس مرورگر معمولاً روی آدرس `http://localhost:8501` باز می‌شود.

## فرمول قیمت
فرمول‌ها مرحله‌ای هستند و با `=` از هم جدا می‌شوند.

مثال:
```
price-7%=price*7=price/8=price+10%
```

در هر مرحله کلمهٔ `price` قیمت خروجی مرحلهٔ قبلی است.

نمونه دیگر:
```
price-17%=price+10%
```

## نکته درباره OCR
برای PDFهای متنی نیازی به OCR نیست. برای عکس یا PDF اسکن‌شده، در صورت نصب Tesseract روی سیستم، برنامه به‌طور خودکار از OCR استفاده می‌کند.

## ساختار داده
فایل‌های بارگذاری‌شده در پوشهٔ `data/uploads` ذخیره می‌شوند و پایگاه داده در `data/tajeritools.db` قرار می‌گیرد.
